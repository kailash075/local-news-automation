# Bundled fonts

Rendering never depends on system fonts. Both fonts are from the Google Fonts repository (github.com/google/fonts, `ofl/` directory) and are licensed under the SIL Open Font License 1.1; the licence texts are kept next to them.

| File | Family | Licence |
|---|---|---|
| `NotoSansTamil.ttf` | Noto Sans Tamil (variable: wdth, wght) | `OFL-NotoSansTamil.txt` |
| `NotoSans.ttf` | Noto Sans (variable: wdth, wght), for Latin text and digits | `OFL-NotoSans.txt` |

`SHA256SUMS` records the downloaded files (2026-10-30). Check with `sha256sum -c SHA256SUMS`.
